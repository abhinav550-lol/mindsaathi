# **MindSaathi – Complete Application Feature List**

## **1. Patient Application**

- User login and authentication.
- Elderly-friendly interface with accessible typography and simple navigation.
- Dashboard displaying daily activities and reminders.
- Access to 5–6 cognitive games.
- Manual game selection.
- Auto Game Mode for automatic game selection.
- Multiple difficulty levels for each game.
- ML-based adaptive difficulty prediction.
- Personalized game difficulty based on historical performance.
- Game score and accuracy tracking.
- Game completion time tracking.
- Hint usage tracking.
- Game performance history.
- Personal Memory Bank access.
- Voice-based memory queries.
- AI-generated responses based exclusively on stored personal information.
- AI Reminiscence Companion.
- Photograph-based memory conversations.
- Voice-based interaction with the AI companion.
- Progressive hints during reminiscence conversations.
- Multilingual AI interactions.
- Medication reminders.
- Hydration reminders.
- Daily activity reminders.
- Game failure notifications.

## **2. Family Application**

- Family member registration and authentication.
- Patient profile association.
- Add and manage personal information in the patient's Memory Bank.
- Store addresses, school names, phone numbers, and important memories.
- Upload photographs for the Reminiscence Companion.
- Add photograph descriptions and contextual information.
- Add multiple hints for each photograph.
- Receive medication reminders.
- Receive game failure alerts.
- Monitor patient game activity.
- View patient game performance and historical progress.
- View relevant performance changes flagged by the ML system.

## **3. Healthcare Provider Application**

- Healthcare provider registration and authentication.
- Healthcare provider dashboard.
- Manage assigned patients.
- View individual patient profiles.
- View patient game activity and performance history.
- Monitor game completion time and scores.
- Receive game failure alerts.
- View unusual performance patterns flagged by the system.
- Create medication routines.
- Configure medication schedules and reminders.
- Manage existing medication routines.
- Monitor patient engagement and activity.

## **4. Machine Learning and AI Features**

- ML-based adaptive difficulty prediction using Random Forest / XGBoost.
- Predict whether game difficulty should increase, decrease, or remain unchanged.
- Personalized difficulty adjustment for individual game categories.
- Performance analysis using accuracy, completion time, hints, and historical scores.
- Adaptive game recommendation and selection.
- Performance trend tracking across multiple sessions.
- Detection of unusual changes in game performance.
- RAG-based personal memory retrieval.
- Context-grounded AI responses.
- Speech-to-text processing.
- Text-to-speech interaction.
- Multilingual AI conversations.
- AI-powered photograph-based reminiscence conversations.
- Contextual hint generation using family-provided information.

## **5. System and Platform Features**

- Role-based access control for patients, families, and healthcare providers.
- Secure patient data storage.
- Patient-specific memory and photograph management.
- Medication and hydration reminder scheduling.
- Notifications and alert management.
- Game performance data storage.
- Synchronization of patient activity and performance data.
- Backend APIs for application modules.

## **6. Later-Stage Features**

- Installable Progressive Web Application (PWA).
- Offline access to cognitive games.
- Local storage of game progress.
- Automatic synchronization when internet connectivity returns.
- Configurable continuous game-session limits.
- Temporary restrictions after a predefined number of consecutive games.
- Extended offline reminder functionality.
